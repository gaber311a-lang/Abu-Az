# موقع أبو عز

أتولييه تصميم جرافيكس — موقع عربي RTL للجوال أولاً.

## كيف تفتح الموقع محلياً

1. افتح مجلد `docs/`
2. شغّل خادماً بسيطاً، مثال:

```bash
cd docs
python3 -m http.server 8080
```

3. من المتصفح: `http://localhost:8080`

أو ارفع محتويات `docs/` إلى GitHub Pages (المصدر: مجلد `/docs`).
