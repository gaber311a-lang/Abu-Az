# موقع أبو عز

موقع عربي (RTL) لمعرض التصاميم وطلب الجرافيكس — واجهة معاينة على GitHub Pages.

## فتح الموقع

- **مباشر على Pages:** https://gaber311a-lang.github.io/Abu-Az/
- **محلياً:**

```bash
cd docs
python3 -m http.server 8080
```

ثم افتح: http://localhost:8080/

## المسارات

| المسار | الوصف |
|--------|--------|
| `#/` | المعرض (الرئيسية) |
| `#/order` | معالج الطلب (10 خطوات) |
| `#/pay` | الدفع (معاينة — بدون خصم حقيقي) |
| `#/orders` | طلباتي (جلسة المستخدم فقط) |
| `#/admin` | الإدارة |

## ملاحظات المعاينة

- التخزين عبر `localStorage` — هيكل جاهز لربط backend لاحقاً.
- تسجيل Google وSMS تجريبيان في الواجهة فقط.
- دخول الإدارة (معاينة): كلمة المرور تظهر مرة في شاشة الدخول (`abu-ezz-admin`) → الجوال `502299827` → الرمز `000000`.
- IBAN للتحويل (معلومات مستفيد عامة): `SA7836036036009631393655`
- لا تتم معالجة مدفوعات حقيقية.
