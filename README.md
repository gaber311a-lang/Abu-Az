# موقع أبو عز

موقع عربي (RTL) للطلب والمعرض — معاينة واجهة على GitHub Pages.

## فتح الموقع

- **مباشر على Pages:** https://gaber311a-lang.github.io/Abu-Az/
- **محلياً:** افتح المجلد `docs/` عبر خادم بسيط، مثلاً:

```bash
cd docs
python3 -m http.server 8080
```

ثم زر: http://localhost:8080/

أو افتح `docs/index.html` مباشرة في المتصفح (قد تختلف بعض ميزات الحافظة حسب المتصفح).

- دخول الإدارة: أي كلمة مرور → الجوال `502299827` → الرمز `000000`.
