**الهوية مقفلة في [`BRAND.md`](./BRAND.md)** — أحمر `#E42C23` على أبيض، شعار `docs/assets/logo-abu-ezz.jpg`. لا تستخدم أصول SEDRA أو اتجاهات Pinterest / بنفسجي.

## فتح الموقع

- **GitHub Pages:** https://gaber311a-lang.github.io/Abu-Az/

```bash
cd docs
python3 -m http.server 8080
```

ثم افتح: http://localhost:8080/
